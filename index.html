About FireBot PWA

FireBot 2.1 preserves the formulas and standard lookup values recovered from the original FireBot 1.02 Android app, and adds a selectable updated coefficient set from the supplied Table 7-3. It has no server dependency and is designed to work offline after the first successful load.

Friction coefficient: choose Standard for the original FireBot coefficients, or Updated to select the nominal hose size and its charged/measured internal diameter from Table 7-3.

Recovered formulas: smooth-bore flow = 29.7 × d² × √NP; friction loss = C × Q² × L; elevation = 0.5 × height in feet or 5 × (stories − 1); PDP = NP + FL + APF + EP.

For flows below 350 gpm, the original app applies 0 psi appliance loss. At 350 gpm or more, it applies 25 psi for a master stream or 10 psi per selected appliance.
